# Три концепции ISEF

## Открытие

Запустить `npm run dev`. В адресе сервера открыть `concepts.html`. Параметр `design` выбирает `ice`, `arena` или `atlas`; параметр `lang` выбирает `ru`, `en` или `es`.

Основной сайт по-прежнему открывается на `/`. Исходные `src/App.tsx`, `src/styles.css`, `src/content.ts` и `src/PuckJourney.tsx` не изменены. Общая сборка выпускает `index.html` и `concepts.html`.

## Направления

| Концепция | Идея | Композиция | Движение |
| --- | --- | --- | --- |
| Линия льда | Пространство для развития спорта | Светлый лёд, крупная спокойная типографика, хоккеист и графика катка, асимметричная галерея | Объёмная шайба парит и совершает пас через первый экран |
| Ночная арена | Энергия игры и международного обмена | Полноэкранная фотография, контурный заголовок, лаймовый акцент, компактный состав команды | Кинематографическое приближение и смещение изображения при пасе, отклик прицела |
| Атлас обмена | Спортивный журнал о сотрудничестве | Бумажная палитра, терракота, курсив, круглая фотография, маршрут стран, аккордеон направлений | Шайба движется по орбите; выбранный пункт маршрута принимает шайбу |

Во всех вариантах есть плавное появление разделов, движение шайбы между выбранными странами, реакции на наведение и индикатор чтения. Системная настройка reduced motion отключает декоративные движения; кнопки и навигация остаются рабочими.

## Материалы

Источник — [макет ISEF](https://www.figma.com/design/iXy6NP58Irini9vMgg9pLf/ISEF?node-id=56-2656) и уже сохранённые материалы проекта. Через Figma проверены первый экран, миссия и структура страницы. После достижения лимита запросов Figma остальные материалы сопоставлены с сохранённым `docs/design-assets.json` и `src/content.ts`.

Это альтернативные художественные решения по запросу пользователя, а не копии расположения элементов исходного макета. Фотографии, логотип, флаги, портреты и карта используются из локальных файлов. Подробная информация фонда и контакты общие с исходным сайтом; новые короткие заголовки и подписи находятся в `src/concepts/copy.ts`. Новая объёмная шайба нарисована средствами CSS, чтобы не растягивать маленькое изображение из макета. Для отсутствующего портрета президента фонда используются инициалы.

## Проверка

`tests/concepts.spec.ts` проверяет три концепции на ширинах 320, 390, 768, 1024, 1440 и 1920 пикселей и на трёх языках. Проверяются выход текста за границы, наличие всех разделов, девяти стран и шести участников команды, загрузка локальных изображений, мобильное меню, смена языка, галерея и возврат фокуса, контакты, прямые ссылки, смена концепции, пас и reduced motion.

Существующие проверки основного сайта сохранены. Снимки для визуальной проверки находятся в `.qa/concepts/` и не входят в сборку. Для запуска проверок: `npm test`; для сборки: `npm run build`.

Сайты доступны локально. Публикация в интернете в рамках этой работы не выполнялась.
