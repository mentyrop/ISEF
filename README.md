# ISEF — Ice Sport Exchange Foundation

Адаптивный сайт на основе [макета ISEF в Figma](https://www.figma.com/design/iXy6NP58Irini9vMgg9pLf/ISEF?node-id=0-1), с переработанной мобильной композицией и типографикой.

React, TypeScript, Vite, Motion. Сайт работает без серверной части и готов к размещению на GitHub Pages. Все изображения и шрифты хранятся локально; внешние шрифтовые сервисы и временные ссылки Figma не используются.

## Запуск

### Три альтернативные концепции

Новые варианты находятся на отдельной странице `concepts.html`. Основная версия на `/` сохранена. После запуска сервера:

- `/concepts.html?design=ice` — **Линия льда**: светлая палитра, объёмная шайба, разметка катка и свободная композиция.
- `/concepts.html?design=arena` — **Ночная арена**: тёмная спортивная подача, полноэкранная фотография, контрастная типографика и лаймовый акцент.
- `/concepts.html?design=atlas` — **Атлас обмена**: тёплый бумажный фон, терракота, редакционная типографика, маршрут стран и раскрывающиеся направления работы.

Верхняя панель переключает концепции и возвращает к исходному сайту. `&lang=en` и `&lang=es` открывают переводы. Все концепции содержат информацию о фонде, миссию, шесть направлений деятельности, девять стран, руководство и экспертов, галерею и контакты.

В каждом варианте работают кнопка «Сделать пас», выбор страны с перемещением шайбы, галерея с клавиатурным управлением, мобильное меню и индикатор прокрутки. Анимации учитывают системную настройку уменьшения движения.

Новые файлы: `src/concepts/Concepts.tsx`, `src/concepts/copy.ts`, `src/concepts/concepts.css`, `src/concepts/main.tsx`. Содержание фонда и локальные изображения используются из существующего проекта. Сборка создаёт обе входные страницы. Подробности концепций и проверки: [docs/concepts.md](docs/concepts.md).

### Локальный сервер

Требуется Node.js 24 и npm.

```sh
npm ci
npm run dev
```

Открыть адрес, который покажет команда запуска. Для проверки готовой сборки:

```sh
npm run build
npm run preview
```

## Возможности

- Русский, английский и испанский языки. Прямые ссылки `/ru/`, `/en/`, `/es/` всегда открывают указанную версию. На главной странице сначала учитывается сохранённый ручной выбор, затем первый поддерживаемый язык из настроек браузера (включая `es-MX`, `en-US`, `ru-RU`); если совпадения нет — английский. Переключатель переводит все разделы, сохраняет выбор и меняет ссылку, не теряя текущую секцию. Старые ссылки `?lang=ru`, `?lang=en`, `?lang=es` продолжают работать.
- Адаптация для телефонов, планшетов и компьютеров. Первый экран использует исходную фотографию фоном с отдельным кадрированием для телефона; раздел деятельности — пунктирную разметку катка на прежнем тёмном фоне. Направления работы образуют единую сетку с разделителями: три колонки на компьютерах, две на планшетах и одна на телефонах; все описания видны сразу.
- Мобильное меню, якорная навигация, полноэкранная галерея с клавишами ← / → и Escape. Диалоги удерживают фокус и возвращают его после закрытия.
- Биографии руководства и экспертов по нажатию на карточку. Вариант «Профиль» без тегов: квадратный портрет рядом с текстом, вертикальная композиция на телефоне, переход к соседнему человеку кнопками или ← / →. Закрытие крестиком, Escape или нажатием на фон. Биографии переведены на RU/EN/ES.
- Анимация появления разделов и открытия мобильного меню. Системная настройка уменьшения движения отключает плавные перемещения.
- Кликабельные телефон, почта и адрес. Карта целиком показывает метку адреса; кнопка под изображением открывает Google Maps по адресу Малый проспект Васильевского острова, 64к1, Санкт-Петербург.
- Оптимизированные изображения WebP, локальные шрифты и ленивая загрузка ниже первого экрана. Исходные файлы макета сохранены отдельно от веб-версий.

Английская и испанская версии подготовлены по русскому тексту макета. Транслитерация имён также находится в `src/content.ts` и доступна для редакторской правки.

Контакты фонда: `info@glazov.me`, `+7 999 514-91-99`, Санкт-Петербург, Малый проспект Васильевского острова, 64к1. В основном сайте используются обновлённые портреты из `src/assets/people`. Схематичная карта в `src/ContactMap.tsx` показывает новое здание у Малого проспекта и 24–25-й линий В.О. (схема, не в масштабе); её подписи переключаются вместе с языком сайта.

После изменения исходных изображений выполнить `npm run optimize:images`. Скрипт создаёт WebP без изменения композиции и сохраняет оригиналы. Для нового PNG нужно добавить его имя и целевую ширину в `scripts/optimize-assets.mjs`.

## GitHub Pages

Репозиторий: [mentyrop/ISEF](https://github.com/mentyrop/ISEF). Рабочий адрес: [isef.pro](https://isef.pro/).

1. Отправить изменения в ветку `main` репозитория `mentyrop/ISEF`.
2. В репозитории открыть **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Запустить workflow **Deploy ISEF to GitHub Pages** во вкладке **Actions** либо отправить новый коммит в `main`.
4. После успешной публикации адрес появится в разделе Pages и в результатах workflow.

Папка `dist` создаётся автоматически. `base: '/'` направляет общие ресурсы в корень собственного домена `isef.pro`, в том числе со страниц языков. После сборки `scripts/build-language-pages.mjs` создаёт настоящие `ru/index.html`, `en/index.html`, `es/index.html` с переведёнными заголовками и описаниями для превью ссылок. Благодаря этому прямое открытие и перезагрузка языковой ссылки работают на статическом GitHub Pages без правил перенаправления и страниц 404. Исходные PDF из папки `ISEF Page` исключены из Git и сборки.

Официальные инструкции: [Vite: GitHub Pages](https://vite.dev/guide/static-deploy#github-pages).

Свой домен настраивается в **Settings → Pages → Custom domain**, затем в DNS у регистратора. После проверки DNS нужно включить **Enforce HTTPS**. Для переноса сайта в подпапку потребуется отдельно адаптировать `base` и языковые маршруты. [Инструкция GitHub по доменам](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site).

Результаты проверки перед первой публикацией: [docs/preflight-2026-09-29.md](docs/preflight-2026-09-29.md).

## Проверка

```sh
npm test
npm run build
node --test tests/language.unit.ts
```

Для браузерных тестов используется Google Chrome. Если он не установлен, выполнить `npx playwright install chrome`.

В тестах проверяются ширины 320, 390, 768, 1024, 1440 и 1920 px на трёх языках, переполнение заголовков, сохранение языка, мобильная навигация, видимость всех направлений, клавиатурное управление галереей, возврат фокуса, загрузка изображений и ссылки для связи.

## Источники и лицензии

- Изображения и графика: предоставленный пользователем файл Figma; новый портрет Сергея Глазова — отдельное фото пользователя. Источники описаны в `docs/design-assets.json`.
- Bebas Neue: [Dharma Type / Fontfabric, семейство 2014 года](https://github.com/dharmatype/Bebas-Neue). Лицензия сохранена в `public/fonts/OFL-BebasNeue.txt`.
- Manrope для основного текста, Unbounded для фирменных подписей: пакеты `@fontsource-variable/manrope` и `@fontsource-variable/unbounded`, SIL Open Font License.
- Небольшие интерфейсные пиктограммы меню, стрелок и галереи: Lucide.

## Примечания к переносу

После первоначального переноса дизайн переработан по просьбе пользователя. Сохранены содержание фонда, изображения и общая спортивная стилистика. В первом экране восстановлена фоновая фотография, в разделе деятельности добавлена пунктирная разметка катка; убраны пустые карточки; добавлены читаемая типографика, отдельные композиции для телефона и компьютера, компактная фотогалерея. По последующим комментариям пользователя возвращено исходное описание фонда и фон на всю высоту первого экрана, убран отдельный блок с шайбой и номера элементов. Заголовок галереи — «Матчи и тренировки», подпись раздела контактов — «Сотрудничество».

Фотографии и флаги взяты из исходного макета; портрет Сергея Глазова заменён на присланное пользователем фото. Неиспользуемые оригинальные декоративные элементы сохранены в `public/assets/` для дальнейшей работы.
