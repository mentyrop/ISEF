# Портреты команды

Оригиналы фотографий находятся здесь. Перед запуском разработки и сборкой сайта автоматически создаются облегчённые WebP в папке `optimized/`; они используются в карточках команды и окнах биографий. Папка `optimized/` генерируется и не хранится в Git. Если сервер разработки уже запущен, после замены оригиналов выполните `node scripts/optimize-portraits.mjs`.

Имена файлов (любое из расширений `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`):

- `vladimir-milyaev.jpg` — Владимир Миляев
- `alexander-glazov.jpg` — Александр Глазов
- `valery-afanasyev.jpg` — Валерий Афанасьев
- `alexander-sazykin.jpg` — Александр Сазыкин
- `alexey-sazykin.jpg` — Алексей Сазыкин
- `sergey-glazov.jpg` — Сергей Глазов

Один файл на человека. Желательно изображение без заранее обрезанных углов, от 600 × 600 px. Индивидуальное кадрирование задаётся в `src/styles.css` правилами `.portrait-frame[data-person="…"]`: ширина, смещение слева и сверху. Оригиналы при этом не обрезаются. После замены снимка проверьте кадрирование в круге и в квадратном окне биографии.
